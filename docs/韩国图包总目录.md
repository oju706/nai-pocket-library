## 去重与按需接入办法

- 顶层保留“画师、同人角色、画面知识”，资源来源、模型、数据包是筛选维度。画风变体不是新的画师身份。
- 画师至少按“模型 + 精确画师标签”归并；图片保留来源包、样图条件和文件指纹。相同画师的不同模型、不同提示词实验不能直接覆盖。
- Curated 应作为“精选筛选”或来源包保留，而不是在全量旁另算一遍人数；实际是否全部属于某包，要用键集合比较后确认。
- WIP、版本号、区间编号不能直接作唯一画师数。先统计各包的实际键名，算交集、独有项和相同图片，再决定是否跳过旧包。
- 前轮已验证 Curated、33000-Q、55000-Q、两份 V4.5、角色包、风格变体包和事件 map 支持 HTTP Range。Curated 已生成约 229 KB 索引并接入应用；其他包尚没有本项目所需的逐图偏移目录。
- 原作者大 JSON 内嵌 Base64 图片，仅知道 URL 不够定位任意图。要么用户先下载本地后建立小索引，要么找到作者公开偏移表；不应把“服务器支持 Range”误写成其他全部图包已经可用。
- 事件 map 自带段表，可单取标签段；style variants 头部名为 `index` 的结构尚未证实是字节偏移索引，不能直接套用。
