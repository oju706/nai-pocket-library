# 自制画师图包

把自己整理的 JPEG、PNG 或 WebP 样图压缩成一个 ZIP。只有一张样图时，可以把图片命名为画师标签。一个画师有多张样图时，用画师标签作为图片的直接上一级文件夹名。

```text
我的画师图包.zip
├── 画师甲.png
└── 画师乙/
    ├── 01.jpg
    └── 02.webp
```

在应用的画师页选择「导入数据包」，选中 ZIP。应用把样图复制到手机上的词库，后续打开条目时读取对应图片。请单独保留原 ZIP，换手机后可以重新导入。重新导入同一个 ZIP 会复用已有记录。

也可以从「工具 → 从 GitHub 下载并解压」填写公开 Release 附件的下载地址，或 `raw.githubusercontent.com` 上的 ZIP 直链。请使用文件直链，不要把仓库网页或 Release 页面地址当作 ZIP。

单张图片最多 12 MiB。每个 ZIP 的压缩大小和解压大小均最多 256 MiB，超过上限时应用拒绝导入，包内最多 10,000 项。应用内的自制图包共可存约 1 GiB；较大的图包可拆成几份分别导入。

作者发布的原版画师大包体积通常远超 256 MiB，请另行下载，并在「导入数据包」中选择原文件；它不属于自制 ZIP 的下载和拆分流程。本文用文字与目录树说明，不依赖外部截图。
