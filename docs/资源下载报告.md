本次 `HEAD` 的重定向路径为 `huggingface.co`（302）→ `us.aws.cdn.hf.co`（200）。初始响应：

```text
x-linked-size: 1030625005
x-linked-etag: "724ee2b0c906159c22ba28566f0d0aa2aee350e81896294ac0ded22c23144fac"
x-repo-commit: 3f9a156edc9cee75f579bd25a22ee98ab47dec52
```

最终 CDN 响应：

```text
Accept-Ranges: bytes
ETag: "9d58a81b3c6310e6370d7b96374241a678bf445e634b6beb1806ff8b99e14a93"
```

两个独立 `GET Range` 请求的实际结果：

```text
Range: bytes=0-1023
206, Content-Range: bytes 0-1023/1030625005, Content-Length: 1024

Range: bytes=100000-101023
206, Content-Range: bytes 100000-101023/1030625005, Content-Length: 1024
```

`x-linked-etag`／文件 SHA-256 与 CDN 的 Xet ETag 是两种不同的标识，不应互相混用。远程读取应验证允许的服务器、206 状态、范围和长度，并将目录绑定到正确文件指纹。固定仓库提交版本能避免 `main` 更新后字节位置失效。

原作者 [55000Q 查看器 ZIP](https://huggingface.co/baqu2213/PoemForSmallFThings/blob/main/NAIA/NAID5_artist_thumbnail/artist_viewer_NAID5F_55000Q.zip) 约 795 KB，内含一个 HTML。研究前段曾在内存中读取它作文本结构检查，未保存为安装软件，也未运行。它扫描用户选择的本地文件建立字节目录，画师统计表用于排序；没有随附可直接下载的预制字节索引。当前 V5、V4.5 原包目录中也未找到这种小索引。
