# 韩国社区 V5 图库与教程收集

核查于 2026-11-08。以韩国社区原帖为入口，分别收藏可复用的画风配方、原图样例和教程。V5 Full 与 Curated 分开记录，SFW、NSFW 和未标注是独立筛选项。

## 分批收集

1. **先做帖子目录。** 从 V5 发布日 2026-08-21 起，按站点、板块和月份记录已查范围。人工选入原帖 URL、帖子编号、作者署名、发布日期、模型声明、附件数、主题和分级。删除或无法访问的条目标明状态，之后按新增日期补录。 [NovelAI V5 发布说明](https://journal.novelai.net/image-generation-novelai-diffusion-v5-is-here-c2df7c6b8d2d/)
2. **核验并挑选。** 优先从原帖的原始附件取得图片。用元数据确认模型和可复用参数，保留原始与随机展开后的提示词。只有作者自述模型时，标为「作者标注」。按文件哈希合并相同图片，目检近似图和连续变体。同组先保留代表图与有比较价值的变体，用主体完整性、画面表现和复用价值做人工精选，点赞数只用于发现候选。
3. **轻量打包。** 每月或每主题一个小包。含原帖链接、作者署名、中文摘要和可用配方，样图用可分享的小预览。完整原图可从原帖按需取得。已有个人收藏单独保留。分包记录新增、重复、元数据齐全和无法访问的数量。

## V5 可复用画风写法

- 水彩材质可试 `faux traditional media, watercolor (medium), painterly`。动画原画质感可试 `production art, animation paper, color trace`。像素质感可试 `pixel art, dithering`。 [官方画风教程](https://docs.novelai.net/en/image/tutorial-artstyles/)
- V5 视觉小说标签包括 `visual novel art`、`visual novel bg`、`visual novel cg`、`visual novel sprite`。四档 `complexity` 控制画面复杂度，测试时固定模型、种子及其他参数，只换这一项。 [官方标签指南](https://docs.novelai.net/en/image/tags/)
- `1.2::painterly::` 加重指定画风词，`0.7::painterly::` 弱化。将一组常用画风保存为 Prompt Chunk 后，可用 `!macro:块名!` 引用。 [权重写法](https://docs.novelai.net/en/image/strengthening-weakening/) · [Prompt Chunks](https://docs.novelai.net/en/image/promptchunks/)
- `||painterly|ligne claire|pixel art||` 每次从三种选项中随机选一项。官方单竖线 Prompt Mixing 支持 V3 及更早模型。 [随机提示词](https://docs.novelai.net/en/image/promptrandomizer/) · [Prompt Mixing](https://docs.novelai.net/en/image/promptmixing/)
