# NAI 口袋词库 Windows 便携版

解压后双击 `NAI-Pocket-Library.exe`。请保留旁边的 `web` 文件夹。应用会打开独立的 Edge 窗口，找不到 Edge 时使用默认浏览器。

- 收藏、主题、画师池和配方保存在当前电脑的浏览器资料中。需要迁移个人词条时，用「工具 → 个人词库备份」导入或导出。
- 韩国主库的目录随应用提供，样图按需读取。也可在「NAX 补充」下载较小的在线目录，再按需看图。在线请求可使用 Windows 手动代理设置。目录无法联网时仍可浏览内置目录和本地词库。
- 「图库 → 选择原图」在本机读取 PNG 文本和 PNG、WebP 的 NovelAI 透明通道隐藏信息。仅含 WebP EXIF 的原图需要在安卓版查看。Danbooru 使用公开接口，站点拒绝公开访问时可点击「打开官网」。
- 「工具 → 法典图鉴」打开原站。在原站复制正向提示词后，可回到「随机画风工坊 → 粘贴提示词」，确认画师和倍率并导入。
- 本地窗口通过 `http://127.0.0.1:17619` 访问该程序；固定地址让下次打开能找到以前的收藏。无浏览器启动参数为 `-no-browser`，主机命令窗口可用 Ctrl+C 停止。
- Windows 便携版与安卓 APK 分开更新。更新 Windows 时解压新版到独立文件夹，保留原有浏览器资料。

从源码构建时，在仓库根目录运行 `pwsh -NoProfile -File ./desktop/build.ps1`。可用 `-Go` 指定 Go 可执行文件，`-Destination` 指定输出目录。
