# NAI 口袋词库

[下载 Android APK](https://github.com/oju706/nai-pocket-library/raw/main/release/NAI-Pocket-Library.apk)

中文安卓 App，用于浏览、收藏和复制 NovelAI 标签与画面提示词。安装 APK 后，手机桌面会出现「NAI 口袋词库」。适用 Android 9 或更新版本，使用系统提供的 Android WebView。

## 1.3.11

- 从原图或样图读取生成的提示词页中，匹配到的画师样图可直接在对应画师行下展开、收起和切换多张图片，不再离开提示词与参数页。图片只在展开或切图时加载，展开状态及当前图片会在原始／实际提示词切换后保留。

## 1.3.10

- 「导入原图生成信息」可从主提示词和角色提示词中识别画风库画师，并查看同画师的库内样图。仅按完整标签精确匹配；`artist:` 标签会保留，当前目录未命中的显式标签仍可查看和复制。
- 「随机发现画师」每批最多展示 10 位，同一画师池记住已浏览的标签。可按当前来源、筛选条件或韩国主库的作品数分档浏览。画师、同人角色和画面提示词知识都可在列表或详情一键收藏到「我的词库」。
- 在线图包可以直接导出离线图文，也可以把小预览和生成信息存入永久图库后再导出。图文 HTML 自带预览、已读取的参数和提示词，可用浏览器离线打开。原图仍可访问时，可按原文件导出 PNG、WebP 或 JPEG。

- 在线社区画风和本地图包支持按 V5、V4.5 或 Full、精选、Full Medium 等具体型号筛选，可和原帖分组、搜索同时使用。已核对的社区合集有 4,425 张模型索引，筛选时只读目录。
- 原图生成参数展示可确认的完整模型名称，原始模型标识仍可单独复制。只有版本、无法确认具体型号时，会标明「型号未核实」。

- 画师、同人角色、画面提示词知识和个人词库的列表统一支持上一页、下一页和页码跳转，本地原图图库也使用同一套分页。普通列表每页 32 条，本地原图每页 24 张。画师全屏图墙随 2、3、4 列切换每页张数，并保留当前浏览位置。只有一页时会收起分页控件。

- 社区画风图库默认按原帖分组，支持只看一帖、输入页码跳转，以及 2、3、4 列图墙。可分别展开或折叠单张图片，也可统一操作。返回上一张、翻页和切换列数会保留当前会话的展开状态。
- 「最近浏览」可找回主动打开的社区图包图片，本机最多保留 100 条条目记录，支持按当前目录清除。图片仍按折叠状态按需读取。
- 「设置与工具 → 在线图包缓存」可查看用量、清除缓存，或设置关闭及 128 MB 至 4 GB 的容量档位。默认 256 MB，按 24 小时未访问和容量上限淘汰较旧缓存。手动下载的原图保存在选定位置。
- 本地图包入口支持带 `batch.json` 的 NAImakeArtistGroup 画风测试 ZIP。使用包内预览显示每组画风，保留原图、模型和 Arca 原帖链接。

- 「画师 → 在线资源 → 在线图包」默认从本项目仓库读取画师资源配置，直接打开原作者的 Arca Live 社区画风合集。图片按需从原站读取，支持检查图包更新、单张下载、多张保存为 ZIP，以及复制生成参数。也可打开「自定义图包」填写其他公开 GitHub 仓库。 [默认资源配置](resource-packs/artist.json) · [在线图包制作说明](docs/自制图包.md)
- 「画师 → 在线资源 → 更多图包 → 打开社区画风图包」可直接选择 NAImakeArtistGroup 的共享画风 ZIP。应用记住原文件的位置，按张读取缩略图、原图和生成信息。移除图包会保留用户下载的 ZIP。
- 韩国主库可每 100 条作品分档，支持和 AA 等名称前缀、关键词同时筛选。

- 画师、同人角色和画面提示词知识都可按名称筛选。选一个 A–Z 字母后，可细筛到 AA–AZ、A0–A9 等前缀，名称中间的空格也兼容。数字、汉字、假名、韩文、其他文字和符号仍各有入口。画师全屏图墙支持 2、3、4 列和“换一批”。“按作品数”使用原作者查看器的作品记录统计。
- 同人角色可填写作品、服装／版本、性别和类型，并在我的词库筛选。类型包含人类、人外和其他。已有角色保留为未标注，可逐条补充。
- “更多图包”可打开原作者的下载页、导入本地原版数据包或自制 ZIP，也可从公开 GitHub ZIP 直链下载并解包。见 [自制图包说明](docs/自制图包.md)。

- **画师**默认打开「韩国主库」。bequiet 的 V5 Curated、33000-Q、55000-Q 合并后有 46,852 位不重复画师，可切回单包。列表直接向原作者服务器按需读取样图。可切换「NAX 补充」或导入自制图包。
- **同人角色**使用 NAX 的 V5 / V4.5 标签和样图。NAX 也提供补充画师数据，进入后可下载约 1.25 MB 共用目录。
- **画面提示词知识**有 33 条原创中文入门知识，按动作、构图、光线、表情、发型、服装和通用写法分类；「在线图鉴」提供 NAX 的 418 条发型／表情样图条目（V5 发型 147、V4.5 发型 152、表情 119）；「原帖资料」保留官方与韩国社区链接。动作、构图、光线尚不是完整韩国带图教程库。
- 每个分类可切换双列看图、图文列表和紧凑文字，并记住显示方式。紧凑文字不加载列表图片。
- 在当前栏点「新增」，填写名称和提示词。备注和配图可选。文字、备注及自己选的配图保存在这台手机。
- 各在线分区有资源检查入口。NAX 检查会同步画师、角色和知识图鉴共用的小目录，有变化时原子覆盖。韩国主库检查核对原文件指纹与目录是否匹配；原文件变化后停止使用旧位置，索引新版当前随应用发布。两者不能等同于已建成独立远程索引仓库。
- 同模型、同画师或角色标签收藏时优先打开已有条目，并补充其他来源样图，保留已有备注。手工新增同标签时提醒编辑已有条目。不同模型独立保留。
- 「工具 → 导入原图生成信息」可逐项复制正负向提示词、采样器、步数、种子等参数，也可复制全部生成参数或勾选后复制。多角色原图可单独复制每位角色的正向、负向和位置。图片含随机展开结果时可切换原始／实际提示词。支持 PNG、WebP 和能识别的 JPEG 元数据。单张上限 32 MB，隐藏信息读取上限 800 万像素。原图没有记录的参数会标明缺失。
- 底栏「图库」支持批量导入 PNG、JPEG、WebP，每批最多 40 张。新导入保存小预览，生成信息读取后按原样留在本机。图库总量按设备可用空间计算，列表分批读取目录。图片详情可删除条目，也可访问仍可读取的完整原图。1.3 及以前导入的完整副本仍可查看和删除。
- 「工具 → 导出备份／从备份恢复」可保存个人条目与自选配图，支持合并或确认后替换。备份限 20 MB。在线图片、完整原包不随备份打包；本地包图片依赖原文件位置，换机或移动文件后可能需要重新关联。
- 「工具 → 检查应用更新」默认在打开应用时每天检查一次，有新版会在 App 内下载并校验 APK。安装由 Android 确认，首次可能需要允许该 App 安装更新。默认仓库读取同一提交下的 `release/update.json` 和 APK，并兼容 GitHub Releases。使用 v1.1 的用户需先手动安装支持该流程的新版。
- 已经有 Arca Live 原版数据文件时，在「画师 → 在线资源 → 导入已有数据包」选择文件。App 在手机上生成目录，后续从原文件按位置读取图片。导入完成后请把原数据包留在选中的位置。

## 构建与发布

当前版本为 1.3.11（versionCode 15），包名为 `app.nai.pocketlibrary`。构建使用 Windows 上的 PowerShell、JDK 17、Android SDK Platform 35 和 Build Tools 35.0.0。

脚本使用下面的便携工具目录。可用 `-ToolCache` 指定目录位置。

```text
.android-tools/
  jdk/<解压后的 JDK 根目录>/bin/java.exe
  platform/android-35/android.jar
  build-tools/android-15/aapt2.exe
  build-tools/android-15/lib/apksigner.jar
  signing/
```

```powershell
pwsh -NoProfile -File .\build.ps1
```

构建会编译、对齐、签名并验证 APK，生成 `release/NAI-Pocket-Library.apk`。首次构建建立发行签名。请把签名密钥和密码文件备份到私有位置。以后发布升级包时沿用包名和发行签名，并递增 `AndroidManifest.xml` 的 `versionCode`。

源码与文档位于 [GitHub 仓库](https://github.com/oju706/nai-pocket-library)。签名后的 APK 随版本发布。发行密钥、缓存和用户数据包由各自的本机目录管理。

发布前用 `tools/New-UpdateManifest.ps1` 生成更新清单，将 `release/update.json` 和签名 APK 放到同一提交。韩国主库索引可用 `tools/generate-korean-index.cjs` 从三份原包分别生成，33000-Q 与 55000-Q 的输出名分别为 `web/korean-33000-index.json` 和 `web/korean-55000-index.json`。再用 `tools/import-artist-counts.cjs` 把原作者查看器的作品数合入索引。

## 后续扩展

页面使用统一条目结构，含分类、名称、模型、提示词、备注、预览和来源。资源转换集中在 `web/sources.js`；网络和文件处理各自独立，方便新增来源。详见 [扩展约定](docs/扩展约定.md)。当前不支持用户安装第三方插件。

后续可增加画风串草稿，从多个画师标签组合权重，按模型保存并预览提示词。再允许从图库原图或角色库带入提示词与参数，最后接入由用户配置的 NovelAI 生图服务。

## 验证范围

安卓代码编译、APK 签名、PNG 解析算法、备份输入校验及更新版本比较已检查。韩国主库抽查首、中、尾三图，通过真实 HTTP Range 取得共约 503 KB，均与本机原包逐字节一致。浏览器按手机宽度检查布局与主要交互。

系统文件选择、隐藏元数据位图解码、安装升级仍需真实安卓手机验证；电脑界面预览不能代替这些检查。
